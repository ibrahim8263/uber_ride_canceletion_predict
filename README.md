# Uber Ride Cancellation Prediction

## Project Description
This project uses Machine Learning to predict the booking status of Uber rides.

## Models Used
- Logistic Regression
- Support Vector Machine (SVM)
- Random Forest

## Dataset
The dataset contains information about Uber ride bookings, including:
- Booking Status
- Vehicle Type
- Ride Distance
- Booking Value
- Driver Ratings
- Customer Ratings
- and other features.

## Target Variable
Booking Status

1. Data Cleaning
2. Exploratory Data Analysis
3. Feature Engineering
4. Data Preprocessing
5. Train/Test Split
6. Model Training
7. Model Evaluation
8. Gradio Interface
